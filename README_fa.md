# دوقلوی دیجیتال پلیتن سوپرهیتر — نسخهٔ ۴٫۰٫۰

مدل‌سازی پایا، گذرا و شروع/توقف گرافیکی مشعل‌ها برای پلیتن سوپرهیتر دیگ بخار یک نیروگاه ۳۲۵ مگاواتی با گردش طبیعی.

- **برنامهٔ اندروید:** Kotlin، Jetpack Compose، Material 3، Hilt، Room، پشتیبانی از راست‌به‌چپ
- **سرور:** Python 3.11، FastAPI، Uvicorn، IAPWS-IF97، SQLite
- **نمودارها:** WebView + Apache ECharts (بزرگ‌نمایی، جابه‌جایی، نمایش/پنهان‌سازی سری‌ها، راهنمای نقطه)
- **ارتباط:** REST روی HTTPS و جریان زندهٔ WSS

## واحدها

همهٔ اعداد در سراسر برنامه، پاسخ‌های سرور و محورهای نمودار تنها با این واحدها نمایش داده می‌شوند:

| کمیت | واحد |
| --- | --- |
| دبی جرمی | تن بر ساعت (t/h) |
| دما | درجهٔ سلسیوس (°C) |
| فشار | بار (bar) |
| توان حرارتی | مگاوات (MW) |
| ضریب انتقال حرارت | وات بر مترمربع-کلوین (W/m²K) |

واحدهای SI فقط در داخل حل‌کننده و در مرز توابع تبدیل می‌شوند.

## هندسهٔ پلیتن

۴۳ پنل و ۴ لوله در هر پنل (۱۷۲ لوله)، لولهٔ ۵۷×۸ میلی‌متر از جنس 12Cr1MoV با طول توسعه‌یافتهٔ ۵۰ متر، دو هدر ۴۰۰×۵۵ میلی‌متر به طول ۱۶ متر. سطح داخلی حدود ۱۱۰۸ مترمربع، حجم داخلی حدود ۱۳٫۴۶ مترمکعب، جرم فلز حدود ۹۸٫۱ تن و ظرفیت حرارتی فلز حدود ۴۹٫۱ مگاژول بر کلوین است. همهٔ این مقادیر از هندسه محاسبه می‌شوند و به‌صورت جداگانه در کد تکرار نشده‌اند.

## سه حالت محاسباتی

۱. **پایا:** موازنهٔ آنتالپی اختلاط بخار اصلی با آب پاشش، جذب حرارت پلیتن و محاسبهٔ دمای خروجی با IAPWS-IF97 همراه با ضریب انتقال حرارت لوله.

۲. **گذرا:** مدل تک‌گرهی فلز (N = 1) با معادلهٔ بقای انرژی:

```
T_out = T_in + h·A·(T_m − T̄_s) / (m_dot·cp)
Q_conv = h·A·(T̄_s − T_m)
dT_m/dt = (Q_gas + Q_conv) / (M_m·C_m)
```

گام زمانی به‌صورت داخلی کوچک می‌شود تا شرط پایداری `dt ≤ 0.5·M·C/(h·A)` برقرار بماند. ثابت زمانی، t63 و t95 گزارش می‌شوند.

۳. **شروع/توقف مشعل‌ها:** ۲۴ مشعل ۴۰ مگاواتی در سه سطح ۹، ۱۲ و ۱۵ متر و در دو ردیف جلو و عقب. حرارت گاز رسیده به پلیتن:

```
Q_burners(t) = Σ 40 MW · load_i(t)
Q_gas(t) = q_platen_fraction · Q_burners(t − gas_lag)
```

با پیش‌فرض‌های ۰٫۱۵ و ۵ ثانیه. هر مشعل بار هدف و زمان افزایش تدریجی جداگانه دارد.

## ضریب انتقال حرارت دینامیکی

در هر گام، خواص محلی IF97 محاسبه و سپس:

```
Re = 4·m_dot_tube/(π·d_i·μ)     Pr = μ·cp/k
Re < 2300 → آرام، Nu = 4.36
2300 ≤ Re < 10000 → ناحیهٔ گذار با درون‌یابی لگاریتمی
Re ≥ 10000 → مغشوش: دیتوس-بولتر یا گنیلینسکی
h = Nu·k/d_i
```

## اجرای سرور

```bash
cd backend
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

مستندات تعاملی: `http://localhost:8000/docs`

اجرا با داکر (سرور + پروکسی معکوس با پشتیبانی WSS):

```bash
cd backend
docker compose up --build -d
```

## ساخت برنامهٔ اندروید

```bash
./gradlew :app:assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

پس از نصب، در بخش تنظیمات نشانی سرور را وارد کنید (مثلاً `https://platen.plant.local/`).

## آزمون‌ها

```bash
cd backend && PYTHONPATH=. pytest -q     # ۷۶ آزمون
./gradlew :app:testDebugUnitTest
```

آزمون‌ها شامل نقاط مرجع IAPWS-IF97، محاسبهٔ دستی دیتوس-بولتر و گنیلینسکی با دقت ۱e-12، مرزهای رژیم جریان، پایستگی انرژی گرهٔ فلز، سازگاری سه حالت شرایط اولیه، تأخیر انتقال گاز و اسکن واحدها در شِمای OpenAPI است.

## محدودیت‌ها

- مدل گذرا در این نسخه تک‌گرهی است و `N > 1` با خطای مشخص رد می‌شود.
- برنامهٔ اندروید برای پیش‌بینی به سرور نیاز دارد؛ فقط تاریخچه به‌صورت محلی ذخیره می‌شود.
- توزیع حرارت مشعل‌ها با کسر ثابت و یک تأخیر انتقال گاز مدل شده است.
